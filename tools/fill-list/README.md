# 대사 작성 목록 (엑셀) 워크플로

미작성 대사 자리(빈 `PRINTFORM` 슬롯)를 엑셀로 뽑아, 대사만 채워 넣으면
스크립트가 원본 파일의 정확한 자리에 한 번에 주입한다.

## 1) 목록 만들기 (엑셀 생성)

```
python tools/fill-list/build_fill_list.py
```

- 대상: `에라마왕 개조판 1.28/ERB/*.ERB`
- 출력: `에라마왕 개조판 1.28/_작성필요_대사목록.xlsx`
- 시트 `작성필요` 열 구성
  - **ID / 파일 / 캐릭터 / 카테고리 / 담당힌트 / 함수** — 어느 이벤트인지
  - **커맨드/장면** — 예: `애무 CFLAG:301`
  - **상황(분기)** — 예: `애무 CFLAG:301 > 두번째 이후 > 애정`
  - **조건식(원문)** — 예: `TALENT:TARGET:85 == 1 && ...`
  - **직전 작성 예시(톤 참고)** — 바로 위에 이미 쓰인 대사(있으면)
  - **작성할 대사 ← 여기에 입력** (노란 칸) — 여기에만 쓰면 됨
  - `_line / _ordinal / _keyword` — 숨김. 주입용 좌표라 **삭제/수정 금지**
- 시트 `요약` — 파일별 빈 자리 개수

## 2) 대사 채우기

- 노란 **`작성할 대사`** 칸에만 대사를 입력한다.
- 한 행 = 한 줄(PRINTFORM 한 개). 여러 줄이 필요하면 아직은 공백/한 줄로.
  (셀 안 줄바꿈은 주입 시 공백으로 합쳐진다.)
- 비워 둔 행은 건드리지 않는다(주입 대상에서 자동 제외).
- 행을 지우거나 정렬해도 됨(ID·`_line`·`_keyword`만 그대로면 주입은 그 값으로 찾음).

## 3) 주입하기 (되쓰기)

```
python tools/fill-list/apply_fill_list.py --dry-run   # 미리보기(파일 변경 없음)
python tools/fill-list/apply_fill_list.py             # 실제 주입
```

- `작성할 대사`가 채워진 행만 처리.
- 안전장치: 해당 라인이 **여전히 빈 슬롯이고 명령어가 일치**할 때만 덮어쓴다.
  이미 채워졌거나 자리가 어긋나면 그 행은 **건너뛰고 보고**한다.
- 원본의 **UTF-8 BOM / CRLF 줄끝 / 탭 들여쓰기 / 라인 수**를 보존한다(in-place).

> 주의: 목록을 만든 뒤 같은 ERB 파일을 다른 방법으로 크게 수정하면 라인 좌표가
> 어긋날 수 있다. 그럴 땐 `build_fill_list.py`로 목록을 다시 만든 뒤 채우면 된다.

## 왕복 자체 검증

```
python tools/fill-list/_roundtrip_test.py
```

임시 폴더에 사본을 만들어 더미 대사를 주입→재읽기 대조→원상복구까지 확인한다.
