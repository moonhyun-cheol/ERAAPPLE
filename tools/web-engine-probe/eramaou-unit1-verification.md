# 에라마왕 콘텐츠 1차 변경 — 스포일러 없는 검증 기록

## 범위

- 승인된 첫 소규모 미완성 구간을 로컬 게임에 구현했다. 게임 전체 완성을 뜻하지 않는다.
- 게임 파일 변경은 `에라마왕 개조판 1.28/ERB/ARCANA_FORT.ERB` 한 개뿐이다.
- CSV, 다른 게임 로직, 엔진, 현재 아이폰 PWA는 변경하지 않았다. 빌드·배포·커밋·push를 하지 않았다.
- 이야기·선택지·해금 조건은 플레이어 요청으로 이 문서와 채팅에서 공개하지 않는다.
- 구현자는 해당 ERB의 주석 및 테스트를 확인할 것. 플레이어는 확인할 필요가 없다.

## 검증 방법과 결과

실제 수정된 ERB, 기존 호출자 `INVASION.ERB`, 기존 `TAX.ERB`, 원래 `VARIABLESIZE.CSV`를 현재 eraJS 시험 엔진에 넣어 **한정된 경로**를 실행했다. 캐릭터 하나와 시작/로드 진입점은 중립적인 테스트 픽스처이며, 화면 표시용 `VITAL_BAR`만 더미로 대체했다. 사용자의 세이브를 읽거나 덮어쓰지 않고 메모리 Map에 저장한다.

1차 실행: 콘텐츠 회귀 테스트 13개, 기존 엔진·원본 무결성 테스트 7개 통과.

- 선행 조건 차단, 실제 메뉴에서 진입 및 취소
- 각 진행 결과, 범위를 벗어난 입력 재시도, 결정 보류 후 재진입
- 전체 10,000개 FLAG 및 돈·날짜·시간·아이템·캐릭터 값의 변경 전후 비교
- 새 VM에 직렬화된 테스트 세이브를 복원하고 반복 방문
- 변경 전 미사용 상태를 가진 **합성 구버전 세이브**에서 진행
- 알 수 없는 상태값 보존
- 신규 게임 초기화 명령과 별도 저장 데이터의 독립성
- 기존 세수 계산과 행동 소모 반환값 유지
- 원본 1,151개 파일 및 `original-inventory.json` 무변경
- 다른 에라마왕 파일, PWA 산출물, 시험 엔진의 SHA-256 변경 전후 비교
- 기존 전투/보상 구간의 텍스트 보존 및 UTF-8 BOM 유지

기존 7개 테스트 중 큰 정수 입력 테스트는 **알려진 반올림 결함이 여전히 존재함**을 확인하는 특성 테스트다. 결함을 고친 것은 아니다.

### 재현 (저장소 루트)

```powershell
node --test --test-timeout=180000 tools/web-engine-probe/eramaou-unit-test.mjs tools/web-engine-probe/test.mjs
```

테스트는 변경 전 보호 기록 `results/eramaou-unit1-protected.json`을 비교용으로 사용한다. 이 파일은 원본 무결성 baseline과 별개이며, 원본을 재생성한 것이 아니다. `--capture-protection`은 수정 전 단 한 번 실행한 준비 옵션이다. 이미 기록이 있으므로 재실행하거나 덮어쓰지 말 것. 이후 다른 콘텐츠를 변경할 때도 이 기록을 조용히 갱신해서 통과시키지 말고 검증 범위를 명시적으로 개정할 것.

## 확인하지 못한 범위

- Windows 네이티브 Emuera 실행판의 전체 플레이 및 실제 `.sav` 호환성
- 새 구간의 iPhone 실행: 이번 콘텐츠는 PWA에 편입/배포하지 않았다.
- 전체 게임 동적 호출·모든 캐릭터 이벤트의 회귀 검증

변경 전 에라마왕 전체를 현재 eraJS에 그대로 컴파일하는 시험은 `GAMEBASE.CSV`의 빈 코드 값에서 실패했다(`Code in GAMEBASE.CSV should be an integer`). 따라서 이번 한정 실행을 전체 게임의 웹 엔진 호환성 통과로 해석하면 안 된다. 해당 CSV/엔진/PWA를 이번 작업에서 임의로 바꾸지 않았다.

## 복구

게임 파일 수정 전 체크포인트: `7950b18e-b32` (`ARCANA_FORT.ERB` 한 파일). 복구는 사용자 승인 후에만 한다. 실제 세이브 삭제, 사이트 데이터 삭제, baseline 재생성은 복구 방법이 아니다.
