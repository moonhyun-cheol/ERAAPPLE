iPhone 설치 · 오프라인 안내

HTTPS 주소를 Safari로 열고 공유 → 홈 화면에 추가하세요. 홈 화면 앱을 연 뒤 아래 준비 버튼을 누르고 완료를 기다리세요. Safari 탭과 홈 화면 앱의 저장소가 같다고 가정하지 마세요.

PWA 확인 중

iOS가 캐시·저장을 삭제할 수 있습니다. 준비 완료는 영구 보존을 보장하지 않습니다. 업데이트는 모든 실행기 탭/홈 화면 앱을 닫은 후 적용됩니다. 저장 후 닫으세요.

세이브 백업 · 복원

게임 안에서 저장 완료를 확인한 뒤 실행 정보 → 실행 중지를 누르세요. 저장한 슬롯과 공통 데이터를 한 파일로 보관합니다. 저장하지 않은 진행은 포함되지 않습니다.

백업 파일 다운로드


백업 파일은 기기 안에서 처리하며 서버에 업로드하지 않습니다.

압축 백업은 iOS 16.4 이상이 필요합니다. 압축 전 256 MiB까지 지원하며 큰 백업은 잠시 시간이 걸릴 수 있습니다. 복원은 현재 게임의 모든 저장을 교체합니다. 먼저 현재 저장을 파일로 보관하세요. 이 웹판 전용이며 PC .sav 호환은 지원하지 않습니다. 다른 탭/홈 화면 앱은 저장 후 닫으세요. 특히 이전 버전 탭은 동시 실행 보호 대상이 아닙니다.

직전 실행: 이전 기록 없음

진단은 마지막 처리 단계만 이 기기에 기록하며 업로드하지 않습니다. 재실행 후 위 직전 실행 내용을 확인하세요. ‘저장 데이터 생성 중/저장소 기록 중’은 완료 확인 전 단계입니다. 기록만으로 강제 종료 원인을 확정할 수 없으며, 정상적으로 앱을 닫아도 미완료처럼 남을 수 있습니다.

후보 엔진 eraJS를 사용한 iPhone 시험용이며 완전 호환은 보장하지 않습니다. 원본 파일은 수정하지 않습니다.

저장은 이 주소의 IndexedDB에 보관됩니다. 백업 메뉴에서 주기적으로 파일에 보관하세요. 최신 실행기는 같은 주소에서 게임과 복원이 겹치지 않게 보호합니다. 저장 중 새로고침/중지는 피하세요. 설정 파일과 일부 KR 확장은 아직 검증하지 않았습니다.
