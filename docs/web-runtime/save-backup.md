# iPhone 세이브 파일 백업 · 복원

## 현재 상태

- 사용자가 실제 iPhone에서 진행·저장·불러오기 및 오프라인 실행 성공을 보고했다.
- 이번 백업 기능은 Edge 및 데스크톱 WebKit 자동 시험을 통과했다. iPhone의 다운로드/공유/파일 선택은 실기기 확인이 남아 있다.
- 릴리스: `deff12b426ac925e946c`.
- 기존 임시 HTTPS 주소를 이용하며 고정 호스팅은 아니다. [접속 정보](../../tools/web-engine-probe/results/iphone-test-link.md).

## 새 버전 받기

1. 게임 안에서 저장 완료를 확인한다.
2. 인터넷 연결 상태에서 `iPhone 설치 · 오프라인 안내` → `오프라인 준비 / 업데이트 확인`을 누른다.
3. 업데이트 준비 후 이 주소의 Safari 탭과 홈 화면 앱을 모두 닫았다가 다시 연다. 사이트 데이터를 삭제하지 않는다.
4. `세이브 백업 · 복원` 메뉴와 새 릴리스 ID를 확인한다.

## 백업

1. 평소 사용하는 홈 화면 앱에서 게임 안의 저장 메뉴로 슬롯에 저장한다. 저장하지 않은 진행은 백업에 포함되지 않는다.
2. `실행 정보 · 저장 주의사항` → `실행 중지`를 누른다.
3. `세이브 백업 · 복원` → `백업 파일 만들기`를 누르고 준비 완료까지 기다린다.
4. `백업 파일 다운로드` 또는 지원 기기의 `공유 · 파일에 저장`을 누른다.
5. 파일 앱에서 `eraTHYMKR-backup-날짜.json.gz`가 실제로 생겼는지 확인한다. 오프라인 복원용은 '나의 iPhone' 등 기기 안에도 보관한다. iCloud 전용 파일은 오프라인에서 사용할 수 없을 수 있다.

백업을 만들었다는 안내만으로 파일 앱에 저장이 끝난 것은 아니다. 다운로드/공유 단계를 마쳐야 한다. gzip 파일은 압축을 풀지 않고 그대로 가져올 수 있다. 서버로 업로드하지 않으며 파일에는 모든 저장 슬롯과 공통 저장이 포함된다. 암호화 파일이 아니므로 타인에게 공유하지 않는 것이 좋다.

## 복원

1. 먼저 현재 저장을 별도 파일로 백업한다.
2. 게임을 중지하고 다른 실행기 탭/홈 화면 앱을 닫는다.
3. 백업 메뉴에서 `.json.gz` 파일 선택 → `선택한 백업으로 전체 복원`.
4. 날짜와 파일 개수를 확인하고 교체에 동의한다. **현재 게임의 모든 슬롯과 공통 저장을 백업 내용으로 교체한다. 병합하지 않는다.**
5. `복원 완료` 후 `실제 게임 시작 / 타이틀로` → 게임의 `불러오기`를 이용한다.

실기기 첫 시험은 중요한 저장이 아닌 시험용 저장으로 수행한다. 데이터 삭제 시험은 자동화의 별도 저장소에서 이미 수행했으므로 실제 Safari 사이트 데이터를 지울 필요가 없다.

## 보호 및 제한

- 이 웹판 eraTHYMKR/eraJS JSON 저장 전용. PC Emuera 바이너리 `.sav` 호환은 지원하지 않는다.
- 게임/엔진/형식/게임 코드/버전을 검사한다. 현재 게임 버전 3210만 허용한다.
- SHA-256으로 변경·손상을 검사한다. 해시는 서명이나 신뢰할 수 있는 출처의 증명은 아니다.
- 중복·잘못된 파일 이름, 부정확한 저장 구조, 손상된 gzip을 거부한다.
- 복원은 하나의 IndexedDB 트랜잭션에서 clear와 모든 put을 처리한다. 취소·검증 실패·트랜잭션 실패는 기존 저장을 유지한다.
- 최신 실행기는 같은 origin의 게임 세션과 백업 작업 사이에 Web Locks를 사용한다. 이전 버전 탭은 이 규약을 모르므로 반드시 닫는다. Safari 탭과 홈 화면 앱의 저장소가 같다고 가정하지 않는다.
- 압축 백업은 iOS 16.4 이상의 Safari가 필요하다. 파일 최대 64 MiB, 압축 해제 JSON 최대 256 MiB. 큰 저장은 시간이 걸리거나 모바일 메모리 한도에 도달할 수 있다. 한도 초과 시 기존 저장을 변경하지 않는다.
- 브라우저 캐시와 내부 저장은 OS가 정리할 수 있다. 별도 백업 파일도 주기적으로 갱신한다.
- 엔진의 일반 저장은 파일별 트랜잭션이다. 게임의 슬롯 저장과 GLOBAL 저장 전체를 하나의 트랜잭션으로 바꾼 것은 아니다.

## 검증

- `test:backup`: Edge/WebKit에서 codec·gzip 왕복, 잘못된 형식·게임·버전·중복·경로·손상 거부, 전체 교체, 동기/비동기 트랜잭션 실패 롤백, 탭 간 잠금 통과.
- `test:pwa-game`: Edge/WebKit에서 실제 게임 저장 → 파일 다운로드 → 잘못된 백업/취소 시 해시 보존 → 격리 DB 삭제 → 파일 복원 → 게임 이름 `웹시험` 및 `밤` 복원 → 오프라인 추가 진행·슬롯 1 저장 통과.
- Edge PWA 캐시/업데이트/오프라인 회귀, WebKit 모바일 레이아웃/계속 버튼, 서버 경계 시험 통과.
- 기존 Node suite는 6/7. 원본 개수를 1,151개로 고정한 검사가 추가 게임 폴더/7z 파일 570개 때문에 실패(현재 1,721개). 기준을 덮어쓰지 않았다. 별도 비교에서 기존 원본 1,151개 모두 변경/누락 없음 확인.
- 결과: `tools/web-engine-probe/results/backup-unit-*.json`, `pwa-game-*.json`, `backup-release-verification.json`.
