# iPhone용 확장형 웹 실행기 설계

상태: **설계 초안 v0.4 — 정적 PWA 시험본·데스크톱 오프라인 저장/로드 성공, 전체 P0/iPhone 실기기 검증 전**

> 최신 단일 게임 시험본: [자동저장 메모리 최적화·로컬 진단](save-memory-optimization.md). 기존 공개본 `5356ae826c56bb47a372`와 LOCAL 지연 할당을 추가한 로컬 후보 `788a65fe4ef13e28da14`를 구분한다. 로컬 후보는 45개 회귀 통과 기록이 있지만 아직 공개 배포 전이며, 사용자 iPhone의 약 4일차 종료는 미해결이다. 아래 제품 설계의 완성을 뜻하지 않는다.
>
> 대형 게임 대응: [대형 ERA 웹 런타임 프로젝트 계획](scalable-runtime-plan.md)과 [M1 재생·메모리·소유권 기준선](m1-baseline.md). 측정 harness와 현재 게임의 함수 코드/런타임 값 소유권 분해는 완료했지만 엔진 선정·코어 재설계·실기기 검증은 완료되지 않았다.

## 목표와 범위

PC를 켜지 않고 iPhone에서 여러 게임을 실행한다. 사용자는 Safari에서 무료 웹 실행기를 열고, 홈 화면에 추가한 뒤 파일 앱에서 보유한 게임 ZIP을 가져온다. 설치 인증서, 유료 계정, 상시 서버 연산은 요구하지 않는다. 최초 접속과 실행기/엔진 다운로드에는 인터넷이 필요하다.

여기서 확장성은 **여러 게임 패키지 + 여러 웹 호환 엔진**을 뜻한다. Windows EXE, Android APK, iOS IPA를 범용으로 실행하는 제품이 아니다. 다른 종류의 앱은 해당 포맷을 처리할 웹 엔진/어댑터 또는 별도 이식이 필요하다.

설계 문서와 격리된 엔진 검증 도구를 추가했다. 원본 게임·설정·Windows 런처를 수정하거나 공개 배포하지 않는다. 실제 게임은 데스크톱 Edge의 Worker에서 타이틀, 초기 설정, 상점 메뉴, 휴식, 슬롯 저장, 페이지 재로드 후 불러오기까지 통과했다. 독립 fixture의 슬롯/GLOBAL 저장 시험도 유지한다. 실제 iPhone과 제품 실행기는 아직 검증 전이다.

정적 PWA 시험본에는 manifest/아이콘, 명시적 오프라인 준비, 해시 검증 캐시, 업데이트 대기와 모바일 화면을 추가했다. Edge의 오프라인 모드와 Windows WebKit 26의 서버 종료 방식으로 실제 게임 재로드·불러오기·추가 저장을 검증했다. **이번 최신 수정본을 공개 HTTPS에 배포하지 않았으며, iPhone에서 검증됐다는 뜻은 아니다.** 현재 시험본은 게임 데이터를 정적으로 묶는 임시 구조로, 아래의 ZIP 가져오기 기반 제품 흐름과 구분한다.

## 사용 흐름

1. HTTPS 실행기를 열고 홈 화면에 추가한다. 설치 안내는 Safari 공유 메뉴 기준으로 제공한다.
2. 파일 앱에서 게임 ZIP을 선택한다. 서버에 게임/세이브를 업로드하지 않는다.
3. 파일 검사 → 엔진/프로필 제안 → 인코딩 미리보기 → 설치 확정 순으로 진행한다.
4. 엔진이 없거나 명령어 지원이 부족하면 라이브러리에 `실행 불가: 사유`를 표시한다.
5. 게임 선택 → 터치/숫자/문자 입력 → 게임 저장. 실행기는 슬롯과 GLOBAL을 관리한다.
6. 파일 앱으로 백업을 내보낸다. 실행기·엔진·게임의 로컬 준비 검사를 통과한 항목만 `오프라인 준비됨`으로 표시한다.

웹 저장소는 OS가 삭제할 수 있다. `오프라인 준비됨`은 영구 보존 약속이 아니며 실행할 때 다시 점검한다. Safari 탭과 홈 화면 앱 사이의 저장소 공유도 전제로 삼지 않는다.

## 결정 요약

- 첫 대상은 eraTHYMKR이지만 공통 계층에 ERB 명령어나 게임 플래그를 넣지 않는다.
- 엔진은 신뢰·라이선스 검토된 빌드만 실행기 레지스트리에 등록한다. 게임 ZIP의 JS/WASM은 실행하지 않는다.
- 원본 ZIP에는 새 파일을 요구하지 않는다. Emuera용 importer가 로컬 메타데이터를 생성한다.
- 저장은 브라우저 IndexedDB를 기준으로 한다. OPFS는 선택적 대용량 최적화이며 필수 조건이 아니다.
- 게임 업데이트/엔진 업데이트/세이브 포맷 변경을 분리하고 기존 저장에 무조건 덮어쓰지 않는다.
- 백엔드·계정·동기화·광고·분석 수집·인증서 배포는 초기 범위에서 제외한다.
- eraJS를 시험용 후보로 사용했지만 제품 엔진은 확정하지 않았다. 실제 게임의 데스크톱 브라우저 최소 저장·로드 경로는 성공했다. 다만 큰 정수 결함, 전체 명령/KR 확장, iPhone 시험이 남아 있어 **전체 P0는 미통과**다.

## 비용의 의미

사용자 측 인증서/서버 비용을 필수로 하지 않는 설계다. 무료 HTTPS 정적 호스팅을 선택할 수 있지만 용량·트래픽·콘텐츠 약관은 공급자별 확인이 필요하다. 도메인 구매와 외부 CDN은 필수가 아니다. 개발 작업량과 무료 서비스의 영구 제공까지 보장하는 것은 아니다.
